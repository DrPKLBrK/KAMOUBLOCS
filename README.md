# KAMOUBLOCS

Générateur et résolveur de blocs d'escalade pour un mur d'entraînement à domicile, en appli web installable (fonctionne sans réseau une fois installée).

Ouvrir : https://drpklbrk.github.io/kamoublocs/ — puis, dans Chrome, menu ⋮ → « Installer l'application ».

Tes données (notes, suivi, séances) restent sur ton appareil ; elles ne sont pas dans ce dépôt.
